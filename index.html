Ageless Linux Docs

Ageless Linux provides tools to remove, replace, and short-circuit age reporting infrastructure mandated by state laws. Currently the project ships a Debian conversion script (become-ageless.sh); it will expand as distros begin shipping compliance mechanisms.

Current Status

No distro has shipped age reporting compliance yet.

California's AB 1043 requires operating system distributors to collect user age information, but no Linux distribution has implemented a compliance mechanism as of this writing. The leading candidate is a freedesktop.org D-Bus interface proposal that would expose an age-bracket property through AccountsService, allowing applications to query a user's reported age group.

Until implementations ship, become-ageless.sh modifies OS identity strings as a preemptive statement of noncompliance. When distros begin adding age collection, the project will provide targeted removal tools for each distribution.
